## 🍃 **Visão Geral**

O **Agrinho** é uma iniciativa educacional de alto impacto que conecta a comunidade escolar às melhores práticas de **sustentabilidade, preservação ambiental e cidadania**. 

Este repositório contém a interface web modernizada do projeto, projetada para proporcionar uma experiência fluida, acessível e engajadora para alunos, educadores e parceiros do meio rural e urbano.

> 💡 **Objetivo:** Conscientizar as novas gerações sobre a importância do agronegócio consciente, ecossistemas sustentáveis e valorização da vida no campo.
