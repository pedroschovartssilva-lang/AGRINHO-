# 🌱 Agrinho

Site desenvolvido com o tema **Agrinho**, destacando a importância da educação, agricultura, sustentabilidade e preservação do meio ambiente.

## 📚 Sobre o projeto

O projeto Agrinho tem como objetivo apresentar informações de forma simples, moderna e visualmente agradável, utilizando tecnologias básicas de desenvolvimento web.

A proposta é criar uma página educativa que conecte temas como:

- 🌱 Agricultura
- 🌳 Meio ambiente
- ♻️ Sustentabilidade
- 📚 Educação
- 💻 Tecnologia
- 🌎 Preservação da natureza

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript
